# 🌸 Pollinations Studio

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

Pollinations Studio is an AI web application for batch image generation and multi-model AI chat powered by **Pollinations.ai** (`gen.pollinations.ai`) and **Bring Your Own Pollen (BYOP)** (`@pollinations/ui` connect).

## Live App
- **URL:** https://pollinations-studio-1.vercel.app/

## Features
- **Batch Multi-Model Image Generation:** Run up to 10 prompts in batch mode and 2, 4, 6, or 10 image requests simultaneously via `https://gen.pollinations.ai/image/`.
- **Custom Model Support:** Select from 10+ built-in models (`flux`, `turbo`, `gptimage`, etc.) or add custom model IDs.
- **Multi-Model AI Chat:** Chat with Pollinations text models via `https://gen.pollinations.ai/v1/chat/completions` with custom system prompts.
- **Bring Your Own Pollen (BYOP):** Integrated with `@pollinations/ui` OAuth connect and Pollinations API keys.
